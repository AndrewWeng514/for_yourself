## 1. 信息架构

### 1.1 入口与切换

- **速记**（`data-tab="thino"`）：默认打开今日；NOTE 仅追加当日日记 `Memos` 段（`- HH:mm 内容`）。
- **日记**（`data-tab="diary"`）：日历 + 粒度（日/周/月/季/年）+ 单页实时预览编辑。
- 实现模式对齐 `stories.js`：切页懒加载 `web/js/thino.js`、`web/js/diary.js`；`index.html` 增加两个 tab 与 `#pane-thino` / `#pane-diary`（预览见 `_diary_preview.html`）。

### 1.2 交叉跳转（避免迷路）

| 来源 | 动作 | 目标 |
|------|------|------|
| 速记 memo 卡片时间戳 | 点击 | 日记页 + 该日 + 粒度「日」 |
| 日记侧栏「今日 Memos」 | 「去速记」 | 速记页，composer 聚焦 |
| 日记侧栏「最近记录」 | 点击行 | 对应日期日视图 |
| 日历周号胶囊 | 点击 | 粒度切「周」并加载 `YYYY-Www.md` |
| doc-meta「所属」行 | **只读展示**，非链接 | 见 §1.3 |

### 1.3 「所属」行 vs 粒度 tabs：去重规则

- **粒度 tabs**（日/周/月/季/年）：唯一控制「当前编辑哪类文件」；箭头按粒度前后移动锚点日期。
- **所属行**（示例：`所属 2026-W43 · 2026-10 · 2026年`）：仅表达**当前锚点日期**在周/月/年坐标系中的位置，**不提供**三个可点的周记/月记/年记链接（预览 v3 已去掉重复链接）。
- **不重复**：侧栏不再放第二套粒度切换；标题区不写「周记：…月记：…」三行 wiki 链（Obsidian 模板首行可保留在 Markdown 源内，网页渲染时 P0 可折叠或灰显为「源文件链接，点击不跳转」）。
- 用户要从日视图进周记：**点周号**或 **切粒度为周** 二选一即可，不必第三入口。

## 2. 编辑器方案（零依赖）

### 2.1 对比

| 方案 | 体验 | 依赖 | P0 代价 |
|------|------|------|---------|
| **A. contenteditable + HTML→MD** | 单页所见即所得，贴近预览 | 无 | 序列化仅覆盖工具栏子集；表格/嵌套列表/混排易损；Memos 段需「不可编辑块」或保存时从磁盘段合并 |
| **B. vendored CodeMirror/Milkdown** | MD 体验好 | 大体积 JS，违背门户零依赖 | 需定 vendoring 策略与升级流程 |
| **C. textarea + 侧栏预览** | 保真高 | 无 | 非已确认 UI；与单页 live-doc 方向冲突 |

### 2.2 推荐：**P0 选 A**

- **加载**：`GET` 得 Markdown → 前端 `markdownToHtml()`（可扩展 `stories.js` 的 `renderMarkdownLite`，或抽到 `web/js/diary-md.js`）填入 `#live-doc`。
- **保存**：`htmlToMarkdown()` 遍历 DOM，输出 UTF-8 LF；**Memos 段**：P0 策略二选一（须用户确认，见 §12）——(1) 编辑器内 Memos 只读，保存时从上次加载的 Memos 原文拼回；(2) 允许编辑但序列化须与 Thino 行规则一致。
- **工具栏**：`document.execCommand` + 自定义块（表格/分割线/图片占位）；撤销栈 P0 用浏览器默认，P1 可自管栈。
- **升级路径**：P1 若保真不足，再评估 **B**（单文件 vendored 放 `web/vendor/`）；或 P1 增加「源码模式」toggle（短时段用 hidden textarea 编辑全文，仍零构建）。

## 3. 日历交互

### 3.1 行为（与预览一致）

- 年/月下拉：无原生箭头样式，文字可点；改下拉只改「日历显示月」，不改变粒度。
- 左右箭头：按**当前粒度**移动锚点（日 ±1 天、周 ±7 天、月 ±1 月、季 ±3 月、年 ±1 年）。
- 网格：周一为首列；左侧 **周号列**（宽 34px）；周号浅灰胶囊 `#f4f5f7`，当前周 `#e8f0ff` + 主色字；有记录周右侧 3px 圆点。
- **行裁剪**：只渲染「与当月 intersect 的周」；`rows = ceil((offset + daysInMonth) / 7)`，**不**为纯下月周单独加一行。
- 相邻月日期：`calendar-cell.other`，灰字 `#c6cad1`，可点则跳转到该日并切换 `calYear/calMonth`。

### 3.2 边界规则

| 情况 | 处理 |
|------|------|
| ISO 第 53 周 | 按 ISO 8601 计算；跨年周归属 ISO 年，周号显示 `53`；文件路径用 ISO 年的 `YYYY-Www` |
| 点击 adjacent 月灰字日 | 更新锚点日期；若粒度为周/月，同步重算加载键 |
| 切粒度 | 保留锚点日期；`week`→该日所在 ISO 周文件；`month`→`YYYY-MM`；无文件时 UI「新建」+ 模板 |
| 周号点击 | `gran=week`，锚点设为该周周一（本地 TZ `Asia/Shanghai`）；高亮周号与周内「选中日」可并存（选中日仍可以是周三） |
| 有记录小点 | 日点：当日存在 day 条目；周点：该周存在 week 文件或周内任一日有 day 文件（P0 可仅 day 索引，P1 加 week） |
| 年下拉范围 | P0：2026–当前年；历史 2023–2025 文件存在但日历默不扩展（P2 路径映射） |

## 4. 图片管线

### 4.1 浏览器

- 压缩：Canvas，`maxSide=2000`，`image/jpeg` 或 `image/webp` quality≈0.85；`createImageBitmap` 绘制即去 EXIF。
- **HEIC**：P0 若 `file.type` 无法解码，提示「请先转为 JPEG」；P1 可选 wasm 解码（仍零后端依赖则放弃）。
- 选项：默认压缩；可选「保留原图」同时上传两份。
- 插入：上传成功后向编辑器插入 `![alt](assets/2026/10/{uuid}.webp)`；展示 `loading="lazy"` + 已知宽高；点击 lightbox（全屏遮罩 + 原图 URL）。

### 4.2 服务端

- `POST /api/diary/assets`：`multipart`，字段 `file`、可选 `original`；校验：≤20MB/张、每条日记最多 5 张引用（保存时校验或上传计数）、**月配额**（默认 200MB/月，可配置）、魔数 JPEG/PNG/WebP、**拒绝 SVG**、文件名仅 `[a-f0-9-]+\.(webp|jpg|jpeg|png)`。
- 路径：`portal-diary/assets/YYYY/MM/{uuid}.webp`；原图 `assets/original/YYYY/MM/{uuid}.{ext}`；解析 Markdown 时禁止 `..` 与绝对路径 → 400 `VALIDATION`。
- 静态：`GET /api/diary/assets/...` 或映射 `portal-diary/assets/` 只读（与现有静态策略一致）。
- 导出 zip：含 `assets/` 树；导入 zip **不**覆盖 assets 除非 overwrite。
- 清理：P2「未引用 asset 列表」+ 手动删除；P0 不自动删。

## 5. 导入器

### 5.1 范围与保证

- **只读**读取 `E:\文档\笔记\1.Diary/**` 与 `Template/**`；写入 `~/文档/portal-diary/`（去掉 `1.Diary` 前缀）。
- **绝不** delete/update 源 vault。

### 5.2 路径映射

| 类型 | 门户相对路径 |
|------|----------------|
| 2026+ 日 | `2026/日记/2026-10-25.md` |
| 2026+ 周/月/季/年 | 见 v2 §4.1 |
| 2025 扁平日 | `2025/2025-06-16.md` **原样** |
| 2023 日 | `2023/2023-04-03 周一.md` **原样** |
| 根目录杂项 md | 原相对路径保留 |

解析日历：P0 索引只认 2026+ 规范 + 扁平 `YYYY-MM-DD.md`；中文星期文件名用正则提取日期键。

### 5.3 流程

- 网页 zip / CLI `python -m app.diary_import`；解压：**zip-slip 防护**（拒绝 `..`、绝对路径）；临时目录 → 逐文件 copy；失败文件记入 `failed[]`，已成功文件**不回滚**（部分成功），响应里区分。
- 幂等：同相对路径 + 相同 sha256 → `skipped`；不同内容 → 查询 `overwrite: false` 则 skip 并标记 `conflict`。
- 导入后：`POST /api/diary/index/rebuild` 或自动增量更新索引；搜索 P1 起用索引标签。

## 6. API 与数据模型

### 6.1 配置

```json
{
  "diary": {
    "root": "/home/user/文档/portal-diary",
    "timezone": "Asia/Shanghai",
    "write_token": "",
    "asset_month_quota_mb": 200
  }
}
```

`app/paths.py` 增加 `DIARY_ROOT`（或仅 config）；**正文不进 SQLite**。

### 6.2 路由（风格同 `/api/stories`：`ok`、`error`、`code`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/diary/entries?from=&to=&granularity=` | 元数据列表（date_key, path, exists, has_memo） |
| GET | `/api/diary/entries/{date_key}?granularity=` | 全文 + sha256 + mtime |
| PUT | `/api/diary/entries/{date_key}` | `{ content, base_sha256?, force? }` |
| POST | `/api/diary/entries` | 从模板新建 |
| GET/POST/PATCH/DELETE | `/api/diary/memos?date=` / `.../memos/{index}` | Memos 段 CRUD |
| POST | `/api/diary/assets` | 上传图片 |
| GET | `/api/diary/assets/{path}` | 读 asset |
| POST | `/api/diary/import` | zip + `{ overwrite }` |
| GET | `/api/diary/export` | zip 流 |
| POST | `/api/diary/index/rebuild` | 可选 |

**错误码**：400 `VALIDATION`、404 `NOT_FOUND`、409 `CONFLICT`（base_sha256 不符）、413 `PAYLOAD_TOO_LARGE`、503 `DIARY_UNAVAILABLE`。

### 6.3 索引（可选）

表 `diary_files(path, granularity, date_key, mtime, sha256, memo_tags)`；重建扫描 `DIARY_ROOT`；保存/导入后更新单行。

### 6.4 Memos 契约（不变）

- 独立行 `Memos`（最后一次出现）；条目 `- HH:mm ` + 内容；续行 Tab 缩进。

## 9. 分阶段交付

### P0（先能用）

- `portal-diary` 目录 + 配置；zip/CLI **导入**；索引扫描（至少 2026 日 + memos）。
- API：entries get/put/post（日）、memos get/post、import、export。
- UI：速记 NOTE + 列表；日记日视图 + 日历（含周号列）+ 方案 A 编辑器**仅 `## 杂记` 区可编辑**（Memos 只读合并保存，降低风险）。
- 图片：上传 + 压缩 + 引用（可 P0 末迭代）。
- **不做**：周/月/季/年正文编辑、memo 删除、全文搜索、AI 工具栏、速记侧 AI。
- **文件**：`app/diary.py`、`app/server.py`、config、`web/index.html`、`web/js/thino.js`、`web/js/diary.js`、`web/js/diary-md.js`、`web/css/style.css`（合并预览样式子集）。

**验收**：导入后今日日记与源 md 一致；NOTE 追加一条可在文件中看到；保存杂记不改变 Memos 字节；导出 zip 可再导入跳过。

### P1

- 全粒度编辑与箭头导航；memos 改删；标签搜索；`base_sha256` 冲突 UI；可选 `X-Diary-Token`；历史 2025 扁平路径日历可选。

### P2

- 2023 中文文件名、未引用 asset 清理、版本历史、反向链接。

## 10. 风险

1. **HTML↔MD 保真**：复杂 Obsidian 扩展语法（callout、wiki 链）可能变形 → P0 限制可编辑范围或保留原始段落注释。
2. **图片原图**：磁盘翻倍 → 默认不保留原图，由用户勾选。
3. **导入路径异构**：日历与 API 键不一致 → 索引 `date_key` 与 `relative_path` 双字段。
4. **写接口无鉴权**：Tailscale 信任模型；公网暴露则必须 token。
5. **无 Memos 段旧文件**：不自动插入（与 v2 审核一致），UI 提示。

6. **保留原图**：默认开还是关？
7. **网页删除**：是否永久禁止 `DELETE` 整篇日记？
8. **历史年份**：P1 是否要在日历浏览 2025 扁平日记？
9. **时区**：Memos 时间一律 `Asia/Shanghai`？
10. **无 Memos 旧日记**：是否提供一键「追加 Memos 段」按钮（仍不自动）？
