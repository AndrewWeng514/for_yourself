## 1. 背景与硬约束

- 门户：`E:\codex项目`，Python 标准库 + 原生 HTML/CSS/JS，零第三方依赖；Ubuntu 部署（`~/文档/dividend-app`，systemd + Tailscale）。

## 2. 已确认的 UI：两个独立板块

侧边栏新增两个页签：**速记**、**日记**。两板块共享同一份日记 Markdown 与 `Memos` 段。

### 2.1 速记（Thino 风格）

- 顶部搜索「在这里输入」；
- 卡片式 composer：
  - 工具栏（AI / 撤销 / 重做 / 标题 / B / I / S / U / 链接 / 图片 / 待办 / 引用 / 列表 / 颜色 / 更多）；
  - 输入区「你现在在想什么？」；
  - 底部 `#` / 表情 / 键盘 / 附件，右侧「粘贴」+ 深蓝 **NOTE**；
- Memos 卡片：`2026/10/25 09:12:00` 时间戳 + 正文 + `#标签` + `...` 菜单；
- 右侧：记录热力图 + 常用标签 + `输入 #标签 来创建标签...`；
- 默认今天；NOTE 写入当天日记的 `Memos` 段，同时更新「日记」页的今日 Memos。

### 2.2 日记（单页实时预览）

- 左侧日历：
  - 年、月下拉（已去掉原生小箭头，文字可点）；
  - 左右箭头按当前粒度前后移动（日/周/月/季/年）；
  - **周号列**：表头「周」，浅灰胶囊显示 40/41/42…；当前周浅蓝底+蓝字；有记录周右侧小圆点；点周号切到周记；
  - 只保留包含当月日期的周（**不要多出整行下个月的周号**）；相邻月份日期灰色补位；
  - 有记录日期显示小圆点；底部「今天 / 有记录 N 天」。
- 右侧文档：
  - 标题 + 一行「所属 2026-W43 · 2026-10 · 2026年」（不再放三个重复的周记/月记/年记链接）；
  - 顶部工具栏：撤销/重做、H1/H2/H3、B/I/U/删除线/行内代码、无序/有序/待办/引用、链接/图片/表格/分割线、清除；浅灰底、sticky、按钮 28px，和正文有明显层次；
  - **单页 contenteditable 富文本实时预览**，不再左右分栏；标题、列表、引用、Memos 直接渲染；
  - 支持插入图片（见 §3）；
  - 底部：保存 / 重新载入 / 状态 / 路径。
- 粒度与时间点：
  - 粒度（日/周/月/季/年）决定“看哪种笔记”，默认今天/本周/本月/本季/今年；
  - 日历的年/月 + 日期决定“哪个时间点”；箭头按粒度前后移动；
  - 非“日”粒度正式版加载对应周/月/季/年文件。

## 3. 图片处理（高分辨率照片）

- 浏览器端先压缩：最长边 **2000px**，WebP/JPEG ~0.85，重编码去 EXIF；可选保留原图；
- 存储：`~/文档/portal-diary/assets/YYYY/MM/<uuid>.webp`（原图 `assets/original/`）；
- Markdown 只写相对路径：`![说明](assets/2026/10/xxx.webp)`；
- 展示：`loading="lazy"` + `width/height` 防跳动，点击 lightbox 看原图；
- 限制：单张 20MB、单条最多 5 张、每月配额；服务端校验 MIME/魔数，拒绝 SVG，防路径穿越；
- 导出 zip 包含 `assets/`。

## 4. 导入现有 Obsidian 日记（不删除原文件）

- 只读复制 `E:\文档\笔记\1.Diary/*` → `~/文档/portal-diary/*`（去掉 `1.Diary` 前缀），`Template/` → `portal-diary/Template/`；
- 保留 2023/2025 历史扁平路径（`2025/2025-06-16.md`、`2023/2023-04-03 周一.md`）原样；
- 导入幂等：同路径同内容跳过；同路径不同内容按 overwrite 选项；返回导入/跳过/失败清单；
- 网页提供 zip 上传导入（后续可复用），首次迁移可由运维直接 scp；
- **绝不修改或删除 `E:\文档\笔记` 下的原文件**。

## 5. 需要 Cursor 优化的重点

1. **信息架构**：两板块的入口、切换、交叉跳转是否清晰；「所属」行与粒度 tabs 是否仍有重复。
2. **编辑器方案**：Markdown 源 + 实时渲染 + 富文本工具栏，在零依赖约束下怎么落地（contenteditable + HTML→Markdown 序列化 vs 轻量 vendored 编辑器）；给 P0 可行方案和取舍。
3. **日历交互**：周号、年月下拉、箭头、点击日期的边界情况（跨月、跨年、第 53 周、点击相邻月日期、切粒度后的选中状态）。
4. **图片管线**：压缩/缩略图/原图/HEIC/EXIF/大小限制/导出/清理策略；服务端接口与存储布局。
5. **导入器**：路径映射、历史异构路径、重名、幂等、失败回滚、zip-slip、非删除保证；导入后日历/搜索如何索引。
6. **API 与数据模型**：entries/memos/assets/import/export；是否建可重建索引；错误码。
7. **移动端**：单列布局、底部工具栏、日历折叠、图片上传、触控尺寸。
8. **UI 细节**：字号/间距/颜色/边框/空状态/加载态/保存态；避免重复信息和视觉噪音。
9. **P0/P1/P2 收窄**：哪些先做，哪些后置；验收标准。
