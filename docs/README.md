# 红利股票配置计算（本地网站）

一个本地启动的小网站，把「红利股票配置计算模板.xlsx」做成网页版，
并把「最新买入价」和「参考股息率」接入实时行情，自动动态更新。
项目按长期扩展设计，后续可不断新增功能页签。

## 一、启动方式

**方式 A：后台常驻（推荐，登录后自动运行、无窗口）**

1. 首次双击 `scripts\install_service.bat`，安装后台服务（登录自启 + 失败自动重启）。
2. 双击 `scripts\start_service.bat` 立即启动一次；之后每次登录 Windows 会自动在后台运行，
   全程无任何终端窗口。
3. 浏览器直接访问 `http://127.0.0.1:8000`。
4. `scripts\status.bat` 查看状态，`scripts\stop_service.bat` 停止，
   `scripts\uninstall_service.bat` 卸载。

**方式 B：双击前台运行（开发 / 临时使用）**

双击根目录的 `启动网站.bat`：
- 若后台服务已在运行，直接打开页面；
- 若未运行，则启动前台服务并自动打开浏览器（关掉窗口即停止）。

两种方式使用同一个地址 `http://127.0.0.1:8000`。

**局域网访问**

1. 服务默认监听所有网卡（0.0.0.0），同一局域网内的手机 / 电脑可直接用
   `http://<本机IP>:8000` 访问；本机 IP 在命令行运行 `ipconfig` 可看到
   （例如 `192.168.31.208`）。
2. 若其他设备打不开，通常是 Windows 防火墙拦截了 8000 端口：
   右键 `scripts\open_firewall.bat`，选择「以管理员身份运行」放行一次即可。
3. 本机仍然用 `http://127.0.0.1:8000` 访问，不受影响。

## 三、功能说明

- 页签「储蓄计划」（默认页）：
  - 页面顺序：总览 → 当前资产快照 → 持仓 → 目标与进度 → 净资产趋势 → 历史明细（默认收起）→ AI 建议。
  - 净资产趋势与周 / 月 / 季 / 年数据走向，趋势图可按周 / 按月 / 按年切换；上升为红色、下降为绿色。
  - 「当前资产快照」点「更新当前资产」，按“资产 / 负债”两级添加自定义模块（可增删），金额填正数；净资产 = 资产合计 − 负债合计；一周内可多次录入，同周取最后一次。资产面板与趋势图全部来自 SQLite 的 asset_snapshots；同一周多次录入取最后一次，不再读取本地笔记。
  - 「当前资产快照」点「从持仓同步」会把股票、基金实仓市值一键填入「中信股票 / 招商基金」，核对后再保存，解决快照与实仓口径不一致的问题。
  - 「持仓」分「股票 / 基金」两个子页签：
    - 股票：点「添加股票」，输入 6 位代码或名称，自动取实时价、股息率、分红；只有实仓股数需要手动填写。
    - 基金：点「添加基金」，输入代码或名称搜索后选择；场外基金取最新公布净值（带净值日期），ETF 取盘中实时价，货币基金按 7 日年化/万份收益展示；基金主指标为近 1 年涨幅，只填份额。
    - 股票和基金都独立于「当前资产快照」；场外基金没有盘中实时净值，页面会明确显示净值日期，不冒充实时。
    - 改完股票股数或基金份额后点「更新」，会先保存再刷新行情/净值；保存失败会停止刷新，刷新失败会提示“已保存但更新失败”。
  - 目标与进度：目标净资产可编辑；「按实际趋势预测」按实际录入日期取最近 3/6/12 个月（默认 3 个月）净资产做线性拟合，得到月均净增；月投默认按历史月均自动计算（负值按 0，可取消勾选「按历史自动计算月投」改用固定值），再按 0%/4%/6%/8% 四档情景测算达标月数与日期。6% 中枢下超过 20 年时橙色加粗提示“暂不能达标”，并对照计划月投的结果。
  - 「AI 建议」（替换原来的「纪律提醒」板块）：把目标、月投口径、历史净值、资产负债、股票与基金实仓和纪律条款汇总后，调用 OpenAI 兼容接口生成 4–6 条中文建议；支持 DeepSeek / OpenAI / 自定义服务。纪律条款在 AI 卡里可折叠展开、逐行编辑并保存（每行一条），作为 AI 建议的依据。
    - 首次使用点「AI 设置」填写服务地址、模型、API Key；Key 只保存在本机 `data\ai_config.json`，也可用环境变量 `DEEPSEEK_API_KEY`。
    - 生成时会把上述汇总数据发送给所配置的 AI 服务；建议仅供规划参考，不构成投资建议。
- 页签「动态选股」：后台每 6 小时自动抓取一次沪深两市全部 A 股（服务启动时也会先检查）；前端切到该页签时才加载/拉取结果，首屏不触发全市场抓取，（收盘价 / PE / PB / 行业）与近 3 年分红数据，先按「股息率 ≥ 阈值、单价 < 50」初筛，再按「股票动态挑选规则整理.xlsx」的硬约束二次筛选并打标签（宏观因子 / 防御底仓 / 银行 / 临近分红）；二次筛选中用「优中选优评分」（股息率、连续分红年数、估值、分红规律、行业防御等）挑出质量最高的 10 只，支持行业、宏观因子、临近分红等过滤，并可将候选一键加入储蓄计划的实仓列表。抓取失败会自动退避重试（20 秒起、最长 300 秒、最多 5 次），仍失败则暂停自动重试并显示「重试」按钮；有旧数据时先展示旧结果并标注失败原因。
- 「小故事」页签：展示每日输出的小故事（frontmatter + 正文 + 自评），支持逐条批注（可引用选中文字）、草稿/发布切换、手动粘贴导入；外部定时任务可通过 `POST /api/stories/import`（body `{"markdown": "..."}`）推送 `daily/YYYY-MM-DD.md`。
- 数据仍在 `stocks` 表统一保存（名称 / 代码 / 权重 / 最新价 / 参考股息率 / 实仓股数）；「配置计算」页签已并入储蓄计划的股票实仓板块。
- 最新买入价：联网后自动获取腾讯实时行情，只展示实时价格。
- 参考股息率：联网后按「最近 12 个月累计每股分红 ÷ 最新价」自动计算，只展示实时结果。
- 股票板块状态灯：绿色 = 实时数据已更新；黄色 = 未获取到实时行情，请点击「更新」重试。

## 四、如何新增一个功能

项目采用「后端 API 路由 + 前端页签 + 独立 JS 模块」的扩展方式，
参考了 Flask 蓝图的模块化思想，但保持零依赖。

1. **后端**：在 `app\server.py` 的 `do_GET` 里「API 路由」区域加一个分支，例如
   `if path == "/api/xxx": self._send_json(...)`。
   复杂逻辑建议放到 `app\` 下新建模块（如 `app\feature_xxx.py`），再在路由里调用。
2. **前端页面**：在 `web\index.html` 的页签栏加一个按钮（`data-tab="xxx"`），
   并在 `<main>` 里加一个 `<section id="tab-xxx">`。
3. **前端逻辑**：在 `web\js\` 下新建 `xxx.js`，用 `fetch("/api/xxx")` 取数据渲染。
   转义、金额、百分比等公共工具统一用 `js\common.js` 的 `DSH.*`，不要再各写一份。
   如需，可在 `app.js` 的页签切换逻辑里保持统一（现有切换已按 `data-tab` 通用）。
4. **数据**：新增的输入文件放到 `data\`，由后端读取。

## 五、数据存储与来源

- 股票配置保存在 SQLite 数据库 data\app.db 的 stocks / settings 两张表中；
  网页上的增删改会直接写入该数据库。
- 资产快照保存在 asset_snapshots 表，items_json 记录“资产 / 负债 + 自定义模块”结构；
- 历史明细的周/月/季/年由快照自动汇总，不单独建归档表；周表只显示周、净资产、较上周，当前表只展示当前年份。
  净资产和同周最后一次快照由后端自动计算。
- 基金实仓保存在 funds 表（份额、最新净值/净值日期、场内价、货基 7 日年化等）；
  行情失败时用上次缓存值兜底，不会把基金市值算成 0。
- 首次运行时，若数据库还没有股票数据，会自动从 data\stocks.json（旧数据）导入；
  若也没有旧数据，则从 data\红利股票配置计算模板.xlsx 导入生成，并在 settings 表写入 `seeded=1`。
  之后即使把股票全部删掉也不会再导入，避免“删空复活”。
  Excel 与 stocks.json 仅作为首次初始化的种子，之后以网页保存的数据为准。
- 最新价：腾讯行情接口（qt.gtimg.cn）。
- 股票查询：东方财富股票搜索接口（按代码或名称解析 A 股）。
- 分红数据：东方财富数据中心（分红送配详情）。
- 基金查询 / 净值：东方财富基金搜索与 F10 历史净值；ETF 行情：腾讯；货基 7 日年化/万份收益：基金页面数据。
- 场外基金没有盘中实时净值，页面会显示净值日期；ETF 为盘中实时价；货币基金按 7 日年化/万份收益展示。
- 股票 / 基金板块未联网或接口失败时不使用静态参考值，页面会显示“—”，请重试。

## 六、说明

- 颜色约定：红 = 上升 / 上涨，绿 = 下降 / 下跌，橙 = 需关注（如 6% 情景超过 20 年、不可达、行业超限），静态金额/股息率/评分使用默认色。
- 本工具仅用于配置计算参考，不构成任何投资建议；实际分红以上市公司公告为准。
