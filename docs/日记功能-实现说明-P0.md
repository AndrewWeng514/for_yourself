## 对 Cursor v3 的修正

1. **补上附件**：v3 漏了 `Annex` 与 `![[...]]`。导入时复制 `Annex` 到 `assets/annex/`，把图片 wikilink 转成标准 Markdown；缺失附件标「（附件缺失：…）」，不中断导入。
2. **补上历史路径**：2023/2025 扁平文件（含中文星期文件名）必须可读；解析器支持 `YYYY/日记/`、`YYYY/YYYY-MM-DD.md`、`YYYY/YYYY-MM-DD 周X.md`。
3. **复杂笔记保护**：有 frontmatter / dataview / 原始 HTML / callout 的笔记默认 **源码模式**，避免 contenteditable 序列化把这些语法改坏；纯 Markdown 日记才用实时预览编辑。
4. **Memos 段**：网页内只读展示，保存时用磁盘最新 `Memos` 原文拼回，避免和速记并发写冲突；速记追加时若没有 `Memos` 段会自动创建。
5. **不建索引**：v3 的 `diary_index.db` 降级为不需要；103 个文件扫描成本可忽略，少一个一致性问题。
6. **编辑器**：P0 采用「简单日记 contenteditable + 复杂日记源码」的混合方案，不承诺所有 Obsidian 语法都能所见即所得。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/diary/entries` | 全部条目元数据 |
| GET | `/api/diary/entry?gran=&key=` | 单篇内容 + sha256 + memos |
| POST | `/api/diary/entry` | 保存（`base_sha256` 冲突 409） |
| GET | `/api/diary/memos?date=` | 某天 memos |
| GET | `/api/diary/memos?all=1&limit=500` | 历史 memos 汇总（带 date/path） |
| POST | `/api/diary/memos` | 追加 memo |
| GET | `/api/diary/calendar?year=&month=` | 月历 + 周信息 |
| GET | `/api/diary/heatmap?year=` | 年度热力 |
| GET | `/api/diary/tags?year=` | 标签计数 |
| POST | `/api/diary/assets` | base64 图片，返回 `/diary-assets/...` |
| GET | `/api/diary/templates` | 模板列表（日/周/月/季/年） |
| GET | `/api/diary/templates/<gran>?key=` | 模板原文 + 占位符渲染结果 |
| POST | `/api/diary/templates/<gran>` | 保存模板源码 |
| POST | `/api/diary/import` | zip 导入（`overwrite=0/1`） |
| GET | `/diary-assets/<path>` | 只读附件 |
